# Predicting Strong Export Growth in Developing Economies

Course: Problem Solving with Data Science
Institution: ITU
Project lane: Markets

## Team

Aliza Masooma — BSEDS23064
Sarah Laeeq — BSEDS23039

## Project overview

This project investigates whether historical macroeconomic indicators can help identify country-years likely to experience strong export growth in developing economies.

## Data source

World Development Indicators (World Bank): https://databank.worldbank.org/source/world-development-indicators

## Project status

Proposal revision and data acquisition preparation.

## Reproducibility

We will document the data source, acquisition process, cleaning decisions, exploratory analysis, limitations, and steps needed to reproduce the analysis.
